### Veld Mining Machines and Supplies — concept build
**Live:** https://veld-mining-portfolio.lovable.app · **Case study:** https://veld-mining-portfolio.lovable.app/case-study

A self-initiated concept project: a multi-page marketing site for a fictional trackless-mining-machinery company, built to demonstrate front-end, motion-design and SEO capability.

**Highlights**
- Scroll-driven **180-frame canvas sequence** scrubbed by scroll position, eased with `requestAnimationFrame` for smooth playback
- `object-fit: cover` maths so the sequence stays full-bleed with **no zoom**, at any viewport
- Fixed backdrop that **persists across route changes**
- Multi-page routing with **per-route SEO** (title, description, Open Graph, canonical)
- Desktop nav → mobile drawer, keyboard-reachable UI, `prefers-reduced-motion` fallback

`TanStack Start` · `React 19` · `TypeScript` · `Vite 7` · `Tailwind CSS v4` · `Canvas API`

> Veld Mining Machines and Supplies is a fictional company. The site is a portfolio concept and does not trade.
